Porkbun Domain Transfer Steps
Domain: johnandsheilaludgate.com
From: Wix  →  To: Porkbun
========================================

WHAT THIS DOES
- Moves ownership of the domain name to Porkbun (~$11/year)
- Keeps the name paid (already good through March 2029; transfer adds 1 year → 2030)
- Does NOT take the website down if you leave nameservers alone during the transfer
- Lets you cancel expensive Wix / iPage website plans later

----------------------------------------
STEP 1 — Prep in Wix (do this first)
----------------------------------------

1. Log into the Wix account that owns johnandsheilaludgate.com
2. Go to Domains (or Settings → Domains)
3. Open the domain
4. Unlock it (turn off transfer lock / “client transfer prohibited”)
5. Get the authorization / EPP code
6. Confirm the registrant email works — approval emails go there

Leave Wix open. You’ll need that code for Porkbun.

----------------------------------------
STEP 2 — Start the transfer at Porkbun
----------------------------------------

1. Log into porkbun.com (after signing up)
2. Go to Account → Domain Transfers
   (or search “transfer” in the dashboard)
3. Enter: johnandsheilaludgate.com
4. Paste the EPP / auth code from Wix
5. Checkout — about $11 for a .com
   - That fee adds 1 year to the existing expiry
6. Pay

----------------------------------------
STEP 3 — Approve the transfer
----------------------------------------

1. Check the email on the domain registration
   (often the account owner’s email; sometimes a privacy relay)
2. Click Approve / Confirm transfer in that email
   - If you skip this, it can sit for up to ~5 days
3. In Porkbun, status should move from “pending” → “complete”

Usual time: a few hours to a few days.
The website stays up the whole time if you don’t change nameservers yet.

----------------------------------------
STEP 4 — After it lands in Porkbun
----------------------------------------

1. In Porkbun, open the domain
2. Turn domain lock back ON (security)
3. Confirm WHOIS privacy is ON (free at Porkbun)
4. Leave nameservers on Wix for now:
   ns1.wix.com
   ns2.wix.com
   so the OLD site keeps working until the new one is ready

----------------------------------------
STEP 5 — After the new site is live
----------------------------------------

1. Point the domain (nameservers or DNS records) to the new hosting
2. Confirm the site loads
3. Confirm any email still works (if using @johnandsheilaludgate.com)
4. Then cancel Wix and iPage so the ~$500/year stops

----------------------------------------
IMPORTANT — DO NOT CANCEL YET
----------------------------------------

Do NOT cancel Wix until:
- The domain transfer is fully complete at Porkbun
- You know where the website will live next
- You have checked any email tied to the domain

----------------------------------------
COST SNAPSHOT
----------------------------------------

- Domain at Porkbun: about $11/year (flat, no big renewal jump)
- Transfer now: ~$11 (adds 1 year; domain already paid to March 2029)
- After move + new site live: cancel Wix/iPage website plans
